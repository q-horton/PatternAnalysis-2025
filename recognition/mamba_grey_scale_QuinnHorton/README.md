# Grey Scale Image Colouriser

***Implemented by Quinn Horton (46975919)***

This model addresses the task of colourising greyscale images by fine-tuning a Mamba pretrained state space model.

## Course Context

This addresses the twelfth task as described in the [COMP3710 - Pattern Recognition and Analysis](https://programs-courses.uq.edu.au/course.html?course_code=comp3710) project specification, so described as:

You can use the this colab notebook as a starting point and refer "MambaIRv2: Attentive State Space Restoration" [\[18\]](https://arxiv.org/abs/2411.15269) for the explanation. You will be given a sample test set of images that needs to be ’reasonably’ colored.
